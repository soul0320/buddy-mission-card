# 내 아이디어 후보

지금 가장 마음이 가는 것 : [한국장학재단 멘토링 사업 및 지역아동센터(7~15세 아동 대상) 등 B2G 공공 조달 시장을 타겟으로, 사전 성향 체크와 유코마블 보드게임 중 발생하는 부작위(10초 주저/스킵) 데이터를 분석하여 맞춤형 짝꿍 미션과 코칭 가이드를 제공하고, 멘토의 1초 반응 피드백을 통해 또래 상호작용 호전 성과 리포트까지 자동 작성하는 보드게임 연동 스마트 멘토링 서비스]

## 후보 1 - 놀이 행동 일간 모니터링 대시보드

- 무엇을 만드나 : 센터장이나 교사가 수집된 아동별 놀이 기록과 타임스탬프를 모아 넣으면, 몇 시에 누가 혼자 있었는지와 케어 필요도가 그래프로 정리되어 나오는 일간 모니터링 대시보드 화면
- 누가 겪는 문제인가 : 늘봄학교 및 지역아동센터에서 인력 부족으로 아동 개별 관찰이 불가능해, 방치되거나 고립된 아동을 한눈에 파악하지 못하는 센터장 및 보육교사
- 팀이 준 말 : 정동원님(영상이나 모션 분석 사용 시 AI 토큰 비용 소모가 커서 향후 확장이 적합함)
- 만들 수 있나 : 단순 타임스탬프 및 사진/텍스트 로그 기반 대시보드는 웹 프로토타입으로 개발 가능하지만, 실시간 영상 AI 분석 연동은 이번 프로젝트 구현 범위를 벗어남

## 후보 2 - 주간 또래 관계 호전 알림 리포트

- 무엇을 만드나 : 일주일간의 놀이 행동 데이터를 모아 집계하면, 주말에 학부모 알림장으로 이번 주 아이가 또래와 어울린 시간, 혼자 놀았던 시간 및 관계 호전 전후 비교 리포트가 전송되는 서비스
- 누가 겪는 문제인가 : 다문화·취약계층 아동이 멘토링이나 돌봄 교실을 통해 실제 또래 관계가 좋아졌는지 객관적 데이터로 확인하고 싶어 하는 학부모 및 지자체/재단 담당자
- 팀이 준 말 : 최유라님(학부모 니즈와 가치는 높으나, 영상/행동 분석 모듈의 토큰 소모 비용이 과도하여 초기 MVP로 진행하기에는 부담이 큼)
- 만들 수 있나 : 수기 수치 입력 기반 템플릿 리포트는 구현 가능하나, 영상 데이터 자동 추출 및 집계 연동까지 진행하는 것은 기간 내 개발이 어려움

## 후보 3 - 보드게임 연동 스마트 멘토링 서비스

- 보드게임(유코마블) 플레이와 연동하여, 참여 아동의 성향과 기피 이력을 분석한 맞춤형 짝꿍 미션과 코칭 가이드를 즉시 띄워주고, 멘토의 1초 반응 피드백으로 또래 상호작용 호전 성과 리포트까지 자동 작성하는 보드게임 연동 스마트 멘토링 서비스
- 누가 겪는 문제인가 : 현장에서 취약·다문화 아동의 정서적 위축과 소외를 풀어주고 싶지만, 아이 성향에 맞춰 어떤 미션과 코칭을 제시해야 할지 몰라 고민하는 대학생 멘토 및 보육교사
- 팀이 준 말 : 팀 공통(영상 분석 대비 토큰 비용이 없어 최우선 Core MVP로 확정)
- 만들 수 있나 : 만들 수 있다. 보드게임 규칙 기반 매칭 및 경량 텍스트/태그 로직으로 동작하여, 토큰 비용 없이 현재 웹/앱 프로토타입(bolt AI 활용 등)으로 즉시 개발 가능함

## 아직 못 버린 것

- [놀이 영상 기반 실시간 안면 랜드마크 분석 및 학부모 자동 리포팅 기능]
- 아동의 미소 지속 시간이나 시선 고정을 영상 프레임 단위로 자동 추출해 주는 기술을 활용할 수 있지만, AI 토큰 비용 소모와 아동 초상권/개인정보 법률 검토 장벽이 커서 뺐지만 미련이 남는다.
