# 넣으면 나온다

한 줄 : 보드게임 미션 칸 도착 시 아동 이름을 선택하면 → 아이에게 보여줄 맞춤 [짝꿍 미션 카드]가 나온다.

- 입력 : 멘토가 미션 칸에 도착한 아동 이름(프로필)을 한 명 또는 여러 명(팀)으로 선택한다.
- 처리 : 선택된 아동(들)의 총인원과 그동안 쌓인 또래관계 데이터를 고려해 2:2, 2:3 등 알맞은 짝꿍 구성을 자동으로 매칭한다.
- 출력 : 아이에게 직접 보여줄 수 있는 [짝꿍 미션 카드] 1장이 화면에 나온다.
※ 멘토 전용 코칭 가이드는 아이에게 보이지 않도록 화면 하단 [코칭 가이드] 탭을 누를 때만 별도로 열리는 보조 화면

- 모양 : 만들어주는 도구 — 아동 이름을 고를 때마다 그 아이에게 맞는 미션을 새로 찾아 만들어 보여주는 입력→처리→생성 흐름이기 때문.

- 잘못 넣었을 때 (1) : 다른 아동의 이름을 실수로 선택하는 것을 방지하고자, 미션을 보여주기 전 고른 아이 이름을 다시 보여주는 확인 화면을 띄운다.
- 잘못 넣었을 때 (2) : 선택한 아동에게 쌓인 성향 데이터가 아직 없으면, 안내 문구 없이 부담이 적은 '보편적 아이스브레이킹 미션'과 '초기 관찰용 코칭 가이드'가 자동으로 매칭되어 나온다.

[보조 기능 및 데이터 선순환 구조]

1. 멘토 전용 코칭 가이드 (보조 화면)
- 아이에게 코칭 지침이 노출되어 위축되지 않도록, 미션 카드 하단 [코칭 가이드] 탭을 멘토가 누를 때만 별도로 열립니다.

2. 1초 피드백 및 DB 누적
- 미션 직후 멘토가 누르는 [1초 또래관계 버튼(좋음/보통/기피)]은 아동 개인의 기분이 아니라, 이번 미션에서 함께한 짝/팀과 얼마나 잘 어울렸는지(또래관계)를 멘토가 그때그때 판단해 누르는 것이며, 함께한 아동들의 프로필 DB에 저장됩니다.
- 처음 만난 조합이라도 첫 미션 후 누른 1초 피드백이 또래관계 데이터로 자동 누적되어, 다음 미션부터는 점점 더 잘 어울리는 짝꿍 조합이 추천됩니다.
- 주의 : [다음 아동 선택]으로 아동 선택 화면에 다시 가도, 누적된 데이터는 초기화하지 않는다.

# 서비스의 화면 흐름 (내가 만듦, "잘못 선택했을 때"는 아직 반영 전임.)

화면 1 — 참여 아동 전체 선택
제목 : 참여 아동 전체 선택
넣는 칸 : 오늘 같이 게임하는 아동들 다중 선택 칸
버튼 : [다음] → 화면 1-1로 이동

화면 1-1 — 미션칸 도착 아동 선택
제목 : 미션칸 도착 아동 선택
넣는 칸 : (화면1에서 고른 아동들 중) 미션 칸에 도착한 아동을 한 명 또는 여러 명(팀) 선택 (다중 선택 가능)
버튼 : [다음] → 화면 2로 이동
상단 [뒤로] → 화면 1로 이동

화면 2 — OO님의 미션
제목 : OO님의 미션
나오는 자리 : 1:1 / 1:2 / 2:2 등 짝·팀으로 구성된 미션 카드 1장
버튼 :
- 상단탭 [미션카드](좌측) · [코칭 가이드](우측)
- 하단탭 [이전으로] · [다음으로]
[코칭 가이드] → 화면 2-1로 이동
[이전으로] → 화면 1-1로 이동
[다음으로] → 화면 3으로 이동

화면 2-1 — 코칭 가이드
제목 : 코칭 가이드
나오는 자리 : 현장에서 바로 활용할 멘토 행동 지침 문구
버튼 : [이전으로] · [다음으로]
[이전으로] → 화면 1-1로 이동
[다음으로] → 화면 3으로 이동

화면 3 — 미션 직후 또래관계 체크
제목 : 미션 직후 또래관계 체크
버튼 : [좋음] [보통] [기피] (아동 개인의 기분이 아니라 이번 짝/팀과 잘 어울렸는지에 대한 멘토 판단)
하단 버튼 : [다음 아동 선택] · [게임 끝내기]
[다음 아동 선택] → 화면 1-1로 이동 (화면 이동해도 누적된 데이터는 초기화하지 않음)
[게임 끝내기] → 화면 1 틀 재사용, 방금 그 아동(들)의 갱신된 프로필
