# 확정 주제

한 줄 정의 : [지역아동센터 대학생 멘토가, 아이의 성향과 기피 이력을 체크하면 맞춤형 짝꿍 미션과 코칭 가이드가 나와, 현장에서 고민 없이 또래 상호작용을 이끌어내고 1초 피드백으로 즉시 반영하는 서비스]

- 쓰는 사람 : 지역아동센터 등에서 다문화·취약계층 아동 멘토링을 진행하는 대학생 멘토

- 넣을 기능 :
  1. 멘토가 아이의 성향·기피 이력 체크리스트를 고르면, 선택한 내용이 성향 태그로 저장된다.
  2. 미션 칸 도착 시 [미션 보기]를 누르면, 아이용 [짝꿍 미션 카드]가 나오고, 하단 탭을 누르면 [행동 코칭 가이드]이 나온다.
  3. 미션 직후 [1초 반응 버튼(좋음/보통/기피)]을 누르면, 아이의 반응이 저장되며, [다음 아동 선택]을 누르면 미션 칸에 도착한 아동을 선택하는 화면으로 전환된다.

- 팀이 이해한 말 : [동원님 - 제가 이해한 건 주사용자(대학생 멘토)의 역할을 아동과 명확히 분리하고, 멘토에게 코칭 가이드를 제공하는 거예요.]

## 마지막 발표에서 보여줄 장면

- [오프라인 보드게임을 하는 아동이 미션게임 칸에 도착 시, '미션 보기'를 누르면 아이 맞춤형 짝꿍 미션 카드가 나오고, 멘토가 하단 '코칭 가이드' 탭을 누르면 멘토 전용 행동 지침이 나온다.]
