# 쓸 사람

- 누구인가 : 대학생 멘토
- 언제 :
  - 지역아동센터나 늘봄학교에서 다문화·취약계층 아동이나 친구들과 잘 어울리지 못하는 아동이, 다른 친구들과 보드게임 등을 하며 놀 때
  - 멘토링 회기가 끝나고 기관이나 장학재단에 낼 활동 보고서를 작성할 때
- 왜 :
  - 아이의 정서 성향이나 기피 특성에 맞는 미션과 소통 방식을 몰라서, 당장 어떻게 해야 할지 모름
  - 부담스러운 단독 발표나 긴 설명 미션을 강요했다가, 아이가 거부감을 보이거나 이탈할까 봐 불안함
  - 멘토링으로 정서나 또래 관계가 얼마나 좋아졌는지, 객관적 데이터로 입증할 수 없음
- 지금은 어떻게 :
  - 체계적인 프로그램 없이 숙제를 봐주거나 단순 놀이, 옆에 있어주는 수준에 머묾
  - 아이가 미션을 주저하거나 기피하면, 임기응변이나 직관으로 다른 카드를 뽑게 함
  - 회기 종료 후에는 객관적 지표 대신 소감문이나 만족도 설문지로 성과 보고를 대신함
- 이 후보로 계속 가나 : [계속 간다 - 매주 멘토링 현장에서 아이 성향에 맞는 미션 지도에 어려움을 겪고 정량적 보고서 작성도 막막했던 대학생 멘토에게 꼭 필요한 실전 도구임]

## 다른 사람이 쓴다면
- [보드게임을 하는 아동이 쓴다면 멘토용 행동 코칭 가이드와 정량 성과 보고서 작성 화면은 숨겨지고, 아이가 직접 주사위를 굴리거나 카드를 확인하는 게임 플레이 화면이 메인에 보여야 함. 보고서와 코칭은 아동 대상 기능이 아니므로 멘토 전용 화면으로 분리돼야 함.]
